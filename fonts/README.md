# 글꼴

본문을 읽는 데 쓰는 한글 글꼴입니다. 원본(OTF)을 **WOFF2** 로 바꿔서 넣었습니다 —
그대로 넣으면 한 벌에 2MB 가 넘습니다.

| 파일 | 크기 | 원본 | 성격 |
|------|------|------|------|
| `RIDIBatang.woff2` | 0.44 MB | 1.39 MB (OTF) | 전자책 본문용으로 만든 명조 |
| `NanumBarunGothic.woff2` | 1.31 MB | 2.23 MB (OTF) | 본문 가독성을 목표로 만든 고딕 |

## 왜 이 두 개만인가

받은 파일에는 굵기별로 여러 벌이 들어 있었지만, **긴 글을 읽기 좋은 본문용
한 벌씩만** 넣었습니다.

- **나눔고딕** 은 바른고딕과 역할이 겹쳐서 뺐습니다
- **나눔스퀘어** 는 각진 제목용이라 긴 본문에 맞지 않아 뺐습니다
- **Bold** 는 한 벌에 1.3MB 나 되는데, 굵게가 필요한 곳은 제목 정도라
  브라우저가 합성하는 것으로 갈음했습니다

## 안 고르면 안 받는다

`@font-face` 로 선언만 해 두었습니다. 브라우저는 **그 글꼴로 실제 글자를 그릴 때**
비로소 파일을 받아옵니다. 그래서 설정에서 고르지 않은 사람은 한 바이트도
받지 않습니다. `font-display:swap` 이라 받아오는 동안에도 글은 바로 보입니다.
